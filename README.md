# My AI software team for Claude Code

Five roles for building websites, mobile apps and SaaS:

| Role | Where it lives |
|---|---|
| Project Leader | CLAUDE.md (the main Claude Code session) |
| Developer | .claude/agents/developer.md |
| Tester | .claude/agents/tester.md |
| Security Checker | .claude/agents/security-checker.md |
| Database Manager | .claude/agents/database-manager.md |

## Setup
1. Copy CLAUDE.md and the .claude folder into the root of your project folder.
2. Open that folder in Claude Code.
3. Ask Claude "which subagents are available?" to confirm the four teammates are listed. (Agents load when a session starts, so start a new session after adding the files.)
4. Give the Project Leader a task, for example: "Build a booking page where customers pick a date and time."

To use the team in every project, copy the four agent files into ~/.claude/agents/ instead.

Docs: https://code.claude.com/docs/en/sub-agents
